# 🗺️ 개발 로드맵

> 기반 문서: docs/PRD.md · 최종 갱신: 2026-11-15

## 📌 개요

- **프로젝트 목표**: Notion 포트폴리오 페이지와 그 하위 문서(이력서·지원서)로 프롬프트를 만들고, 사용자가 ChatGPT 등에서 실행해 붙여 넣은 결과를 검증·병합해 하나의 최신 이력서로 만든 뒤, 사용자가 검토·수정하고 Notion에 새 페이지로 저장한다. API 키·과금 없음. (PRD §1)
- **MVP 범위**: 포트폴리오 하위 문서 조회 / 프롬프트 생성 및 AI 결과 붙여넣기 검증 기반 경력 병합·문서 기반 보강 / 미리보기·diff·출처·수동 수정 / Notion 새 페이지 저장 (PRD §3, §8)
- **제외 범위**: 회원가입·다중 사용자, PDF·DOCX 내보내기, 공고 맞춤 생성, 버전 롤백 UI, 항목 단위 diff 고도화(후속), DB 기반 조회·필터 (PRD §1.3, §8)
- **기술 스택**: Next.js 15.5.3 (App Router) · React 19 · TypeScript · Tailwind v4 · shadcn/ui · Zod · `@notionhq/client` · Vercel (AI는 수동 연계, SDK 없음)
- **현재 코드 상태**: 스타터킷(랜딩, login/signup, shadcn UI) + SDK 설치 + `env.ts` 환경변수 검증 + `.env.example`. 이력서 기능은 미착수.
- **데이터 소스(확인됨)**: 이력서·Q&A DB는 없다. 포트폴리오 페이지 1개 아래 하위 페이지 4개(손문배, 지원서*20260920, 손문배 이력서(삼성글로벌리서치), 손문배*입사지원서)를 읽는다. 모든 페이지의 속성은 title뿐이다. (PRD §5)
