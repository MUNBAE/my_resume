# 🗺️ 개발 로드맵

> 기반 문서: docs/PRD.md · 최종 갱신: 2026-11-14

## 📌 개요

- **프로젝트 목표**: Notion에 흩어진 여러 이력서와 Q&A 답변을 Claude API로 하나의 최신 이력서로 병합하고, 사용자가 검토·수정한 뒤 Notion에 새 페이지로 저장한다. (PRD §1)
- **MVP 범위**: Notion 이력서·Q&A 조회 / Claude 경력 병합 및 Q&A 보강 / 미리보기·diff·출처·수동 수정 / Notion 새 페이지 저장 (PRD §3, §8)
- **제외 범위**: 회원가입·다중 사용자, PDF·DOCX 내보내기, 공고 맞춤 생성, 버전 롤백 UI, 항목 단위 diff 고도화(후속) (PRD §1.3, §8)
- **기술 스택**: Next.js 15.5.3 (App Router) · React 19 · TypeScript · Tailwind v4 · shadcn/ui · Zod · `@notionhq/client` · Anthropic SDK · Vercel
- **현재 코드 상태**: 스타터킷(랜딩, login/signup, shadcn UI, `src/lib/env.ts`)만 존재. 이력서 기능은 미착수. (PRD §8의 `[x]`는 요구 범위 표기이며 구현 완료가 아님)
